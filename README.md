## About Me

I'm a student developer from Vietnam who enjoys building useful digital products with code and AI.

I like creating projects that are practical, visual, clean, and product-focused.

My goal is not just to generate code.  
My goal is to build projects that feel like real products.

I use AI as a development assistant for:

- planning product ideas
- writing and improving code
- debugging errors
- creating documentation
- improving UI/UX
- designing system structure
- building prototypes faster
- upgrading existing projects
- learning new technologies

AI helps me move faster, but every product still needs testing, review, and improvement.

## Product Mindset

I believe AI gives individual creators the power to build projects that used to require a full team.

But AI is not magic.

A real product still needs:

- clear purpose
- clean interface
- working features
- safe logic
- error handling
- testing
- documentation
- user feedback
- continuous upgrades

My workflow usually looks like this:


## AI-Assisted Development

> [!IMPORTANT]
> Most of my products are created with the assistance of artificial intelligence.

AI helps me move from idea to prototype faster.

I use AI for:

- brainstorming
- planning
- coding
- debugging
- refactoring
- UI ideas
- documentation
- system design
- test planning
- feature upgrades

But I do not treat AI output as perfect.

AI-assisted projects can still contain:

- bugs
- incomplete features
- security weaknesses
- incorrect logic
- unstable behavior
- broken edge cases
- poor performance
- unfinished UI
- missing validation
- wrong assumptions

That is why every project should be reviewed, tested, and improved before real use.
